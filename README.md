# Magic for World

Shadowrocket subscription files filtered from public VPN subscription sources.

## Files

- `subscriptions/shadowrocket-filtered.txt`: plain Shadowrocket-compatible node list
- `subscriptions/shadowrocket-filtered-base64.txt`: Base64-encoded subscription content
- `subscriptions/selection-summary.json`: filtering summary

## Shadowrocket Import

Use the raw GitHub URL for `subscriptions/shadowrocket-filtered.txt` after this repository is pushed to GitHub.

Example:

```text
https://raw.githubusercontent.com/<user>/<repo>/<branch>/subscriptions/shadowrocket-filtered.txt
```

If your client expects a Base64 subscription, use:

```text
https://raw.githubusercontent.com/<user>/<repo>/<branch>/subscriptions/shadowrocket-filtered-base64.txt
```

## Automatic Updates

GitHub Actions runs `scripts/update_subscription.py` every day at 00:05 Beijing time and commits changed subscription files back to the repository.

You can also run it manually from the Actions tab with the `Update Subscription` workflow.

## Filtering Notes

The current subscription was generated by:

- parsing the original public V2Ray subscription
- removing duplicate server endpoints
- checking basic TCP connectivity
- sorting by lower connection latency
- keeping a diversified set of 80 nodes

Real proxy availability may still vary. Run Shadowrocket's built-in latency test after importing.
